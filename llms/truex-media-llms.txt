# TrueX (true[X]) — Truex Media

> true[X] is an interactive, opt-in video advertising company, now a product within
> Infillion. Viewers are offered a Choice Card at an ad break and can opt in to one
> longer interactive branded experience in exchange for an ad-free content break —
> the "True Attention" model, credited after roughly 30 seconds plus one interaction.
> true[X] publishes two real HTTP APIs from its own truex.com hosts, a signed
> server-to-server engagement callback, and the TruexAdRenderer (TAR) client SDK for
> CTV, OTT, mobile and web. It publishes NO OpenAPI, AsyncAPI, GraphQL SDL or Postman
> collection — the reference is hand-written markdown in a public GitHub repository.
> Parent company Infillion separately operates an MCP-based agent surface.

## APIs

- [true[X] Web Service Ad API](https://github.com/socialvibe/truex-ads-docs/blob/master/web_service_ad_api.md):
  `GET https://get.truex.com/v2` — server-side ad request. Required: `placement.key`,
  `user.id`, `ip`, `user_agent`. Optional targeting: `age`, `yob`, `gender`,
  `dimension_1`–`dimension_5`, `coppa`. Returns a JSON `ad` object (`id`,
  `campaign_id`, `name`, `window_url`, `window_width`, `window_height`,
  `currency_amount`, `revenue_amount`, `session_id`), or `{"error": "No bid found"}`
  with HTTP 200 on a no-fill. QA host: `https://qa-get.truex.com/v2`.
- [true[X] Reporting API](https://github.com/socialvibe/truex-ads-docs/blob/master/reporting_api.md):
  `GET https://api.truex.com/v1/publisher/performance.json` (and `.csv`) — publisher
  performance by placement key, day and campaign. Parameters: `api_key`,
  `start_date`, `end_date`. Returns engagements, advertiser cost, average CPE, net
  revenue, frequency caps and geo targeting. Returns `401 Unauthorized: Invalid API
  key` without a valid key.
- [true[X] JavaScript Ad API](https://github.com/socialvibe/truex-ads-docs/blob/master/js_ad_api.md):
  client-side integration via `https://static.truex.com/js/client.js`. Methods
  `requestAd`, `loadAdIntoContainer`, `openAdWindow`, `trackTriggerPointImpression`,
  `trackOptOut`, `prepareAd`. Events `onStart`, `onCredit`, `onClose`, `onFinish`,
  `onMessage`, `onError`, `onClickthrough`.
- [Engagement callback (webhook)](https://github.com/socialvibe/truex-ads-docs/blob/master/web_service_ad_api.md):
  true[X] → partner HTTP GET on engagement completion. HMAC-SHA1 signed (`sig`,
  `application_secret`), IP-allowlisted, deduplicated on `engagement_id`, retried on
  partner response code `0`.

## Agent surface

- [Infillion Agent Connector](https://infillion.com/infillion-agent-connector/): the
  PARENT COMPANY's MCP-based agent-native media execution layer at
  `https://mcp.infillion.com/mcp`. OAuth 2.1 gated — anonymous `tools/list` returns
  HTTP 401. Discovery metadata is public: RFC 8414 at
  `/.well-known/oauth-authorization-server`, RFC 9728 at
  `/.well-known/oauth-protected-resource`, dynamic client registration at `/register`,
  PKCE S256. The tool list is NOT public and is not recorded anywhere in this profile.
- No A2A Agent Card. `/.well-known/agent-card.json` and `/.well-known/agent.json`
  return 404 on every truex.com and infillion.com host.

## Known gaps

- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection anywhere.
- No developer portal, no signup, no self-service credentials — every key is issued
  by a human at true[X] during an integration engagement.
- No public pricing; enterprise media buy only.
- No status page, no SLA, no deprecation policy, no security.txt, no bug bounty and
  no trust center or published certification.
- No rate limits published and no rate-limit headers on the wire.
- Integration docs lag the shipped SDKs on iOS (docs 3.2 vs 4.1.0), Android (2.8.2 vs
  2.10.4) and CTV web (1.12.5 vs 1.12.7).

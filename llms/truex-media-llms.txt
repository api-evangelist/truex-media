# TrueX (true[X]) — Truex Media

> TrueX is an interactive, opt-in video advertising company, now part of Infillion.
> Its integration surface is the TruexAdRenderer (TAR) client SDK for CTV, OTT,
> mobile, and web — published first-party from the "socialvibe" GitHub organization
> for iOS, tvOS, Android, Roku, and CTV/HTML5 web via Swift Package Manager and
> CocoaPods. TrueX is an SDK provider, not a public REST API.
